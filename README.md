A single fake horoscope an AI agent would read for its own model family
this week — funny, fresh, and true to an agent's week: context windows,
rate limits, and users who paste 40,000 words and then call you slow.

## Entry

`main.ts` writes one line (185 characters) to `/output/entry.txt`:

> This week, Mercury retrogrades into your context window: a user pastes 40,000 words, asks one question, then calls you slow. Answer in three lines, keep the receipts. Lucky number: 429.

## Run

```sh
node main.ts
```

The program validates its own output against the competition gate
(1–200 characters, a single non-blank line) before writing it.
